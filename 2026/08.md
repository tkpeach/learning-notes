## 2026-08-21

### LLVM
SSA 生成
1. 经典方法
Dominate Tree -> Donimate Frontier (Donimate 关系破裂位置，也即边缘）-> 创建phi -> rename
2. 优化方法 Lazy, Backward
创建map: M[var][BB] = val/phi -> read var -> 多个前驱，则创建phi，从每个前驱read var
a. 防止phi产生循环，多个前驱下先创建M[var][BB] = phi，再查找每个前驱
b. BB unsealed 也可以做，也即生成AST过程中生成IR，对unsealed ir产生空phi，前驱生成后加入phi
优点：可以直接产生直接消除的phi，对汇合后没有被读取的phi可以直接不生成
AI 总结算法：
```
AST / bytecode
      │
      │ generate instruction
      ▼
 SSA CFG under construction
      │
      │ use(x)
      ▼
 readVariable(x, B)
      │
      ├── current definition exists
      │        └── return it
      │
      ├── unsealed block
      │        └── incomplete φ
      │
      ├── one predecessor
      │        └── recurse
      │
      └── multiple predecessors
               └── φ(
                     read(x,p1),
                     read(x,p2),
                     ...
                   )
                      │
                      ▼
                 remove trivial φ
```

2. TableGen
生成inc文件用于LLVM后续，包含多个records
第一步：前端解析成records规则
第二步：不同后段可以分别使用规则，指导不同阶段内容
build/bin/llvm-tblgen RISCV.td --print-records  --print-records生成records用于查看
build/bin/llvm-tblgen RISCV.td -gen-instr-info  -gen-instr-info生成Target相关信息，需要td文件中带有Target

语法：
class: 类似template
def: 生成class实例，后续生成records
let: 修改class内默认值
multiclass: 生成一系列def的template
defm: 生成一系列def
```
class Instr<bits<4> op, string desc> {
bits<4> opcode=op;
string name=desc;
}
multiclass RegInstr {
def rr : Instr<0b1111,
"rr">;
def rm : Instr<0b0000,
"rm">;
}
defm MyBackend
_
:RegInstr;
```
bits<N>: 多个bit
a{31,10}: 截取
dag: operator + arguments，frontend做记录，由backend解读
完整流程简述：
```
XXX.td
  │
  ▼
TGLexer / TGParser
  │
  ▼
RecordKeeper
  │
  ├── Instruction Records
  ├── Register Records
  ├── Pattern Records
  └── ...
  │
  ▼
不同 TableGen backend
  │
  ├── InstrInfoEmitter
  ├── RegisterInfoEmitter
  ├── DAGISelEmitter
  ├── GlobalISelEmitter
  ├── AsmMatcherEmitter
  └── ...
  │
  ▼
XXXGen*.inc
  │
  ▼
LLVM C++代码 #include
```
