# Rust 生命周期：1–2 小时入门

[专题目录](../README.md) · [仓库首页](../../README.md)

## 目标与范围

面向已有编程经验、需要补齐 Rust 借用基础的学习者。目标：判断引用是否有效，读懂和写出简单生命周期签名，知道何时可以省略标注。先补齐 String、&str、作用域和所有权；本次不展开变型、HRTB、复杂 trait 和异步借用。

当前进度（2026-10-21）：L01–L05 及编译器机制已讲解；M04-R 综合回访两项判断正确，正按追问补充 to_owned/Clone/Copy 及 copied/cloned 的 API 机制。所有权与借用关系已有应用证据，转换 API 和独立方法实现仍需后续巩固。以下是建议时间预算，并非实际耗时记录。

## 记录规则

- 教学以完整模块为单位：先给直觉、机制、语法写法、对比例子与边界，再一次布置 3–4 道练习，集中反馈；不逐个小问题等待回复。每轮材料支持约 15–25 分钟独立学习，按实际情况调整。
- 每轮反馈保留正确判断与误区，集中解释共性原因；基础缺口优先在讲义补齐，不用连续猜题代替教学。
- 讲义保存正确解释和教学示例；练习答案在尝试后反馈。
- 日志保留有价值的原始判断及纠正，不复制整段聊天，不自动标为掌握。
- 复习笔记提炼已讨论的结论、反例和折叠自测答案，链接回练习与卡点。
- 年月日志只记当天一句话结论、最多两三个关键点和链接，形成结论后再添加。
- 代码按题号保存；需要修复时保留原始失败案例，另存修复版。构建产物写入临时目录。
