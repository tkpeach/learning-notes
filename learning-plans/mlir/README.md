# MLIR 从零开始：学习计划、独立提示词与练习

[返回学习专题目录](../README.md) · [返回仓库首页](../../README.md)

整理日期：2026-09-17。本文收录本次对话确定的 6 阶段、24 章路线与 48 道简易练习，并提供阶段级、章节级两种独立提示词。

## 目标与使用方式

目标是读写 MLIR、用 C++ 开发 Pass/Rewrite/自定义 Dialect、完成高层表示到 CPU 执行链路，并开展基础优化、正确性验证与源码阅读。主线先覆盖 CPU；GPU、动态形状、量化、稀疏计算、DataFlow 和 Python Bindings 可作为后续专题。

- **一次学一章**：复制相应章节的整个 `text` 代码框到新会话，无需复制本文开头或其他章节。
- **在一个窗口学完整阶段**：复制该阶段的“阶段独立提示词”。其自身包含范围、练习、工具和教学要求，不需要再粘贴四章提示词。
- 独立表示不依赖以前的文件与学习输出；较深章节仍有知识前提，提示词要求教学者在当前会话补齐。
- 每章有两道小练习。后期小练习默认基于教学者提供的完整工程骨架，不要求初学者仅凭题目从头实现大型编译器。
- 这是一份计划，不是已完成的学习记录。建议先按 01—24 顺序推进，再单独重学需要的章节。

## 在线工具与验证范围

| 入口 | 用途 | 限制 |
| --- | --- | --- |
| [MLIR Compiler Explorer](https://mlir.godbolt.org/) | MLIR 解析、验证、Pass 与中间 IR 观察 | 以实际提供的工具版本和参数为准，不默认支持自定义插件或程序执行 |
| [Compiler Explorer](https://godbolt.org/) | C/C++ 基础实验，LLVM IR 与汇编观察；页面实际支持时运行程序 | 普通 C++ 环境不代表已配置 MLIR 开发库 |
| [MLIR Playground](https://playground.mlir-china.org/) | 小型 C++ Pass、Rewrite、DRR、Toy 预设实验 | 适配其内置版本，不能把 DRR 预设当作任意 ODS/CMake 工程支持 |

网站入口和 Playground 能力已核查公开页面及[项目说明](https://github.com/MLIR-China/mlir-playground)。本次交互编辑器加载超时，未实际在线跑通全部练习；学习时须重新确认可用性、版本与具体能力。这不是 48 道练习已通过的测试报告。

验证分为四层：

1. **解析与验证**：语法及已实现的 IR 约束被接受。
2. **变换检查**：Pass 输出结构符合预期。
3. **数值执行**：真实运行结果与参考实现一致。
4. **性能测量**：在正确基线上比较实际执行成本。

`mlir-opt` 能解析、验证和运行 Pass，通常不会直接执行输入程序；见[官方工具说明](https://mlir.llvm.org/docs/Tutorials/MlirOpt/)。不能把前一层通过当成后一层已完成，也不能把 verifier 当作所有访存安全或数学等价性的证明。

## 路线与导航

建议约 **160—240 小时**，仅为安排估算。完全没有编程经验时额外补充基础，不必为赶进度跳过验收。

| 阶段 | 章节 | 目标 | 建议投入 |
