# 业界进展

### DeepSeek-V4.1-Flash-1017：代码 Agent 能力提升，权重与调用链一起开放

**质量：A｜重要性：高｜Personal Utility：高｜原始发布：2026-10-17，此前漏报。** [中文发布说明](https://api-docs.deepseek.com/zh-cn/news/news261017/)、[官方更新日志](https://api-docs.deepseek.com/zh-cn/updates/)与[模型权重](https://huggingface.co/deepseek-ai/DeepSeek-V4.1-Flash-1017)共同确认：这是 V4.1 Flash 的新版本，已覆盖网页、App 和 `deepseek-flash` API；接口名与模型 token 单价维持不变。旧模型名仍可调用，但会被路由至新版。模型卡列出约 **763B 总参数**、**MIT 许可**、**1M 上下文**，并提供 prompt 编码参考实现、推理说明以及将 Chat Completions/Responses 请求转换为模型格式的 `deepseek-recipe`。这些资产使第三方有条件复测，不能把“开权重”直接等同于已经有成熟、同配置的多后端部署。

**相对旧版的增量。** 官方模型卡给出 V4.1 Flash → 1017 的同表比较：Terminal-Bench 4.0 **31.2→42.3**，ProgramBench **20.3→29.1**，DeepSWE v1.1 **74.2→77.0**，NL2Repo-Bench **65.4→68.2**；HLE 无工具 **36.8→42.6**。改进以复杂代码和 Agent 任务最醒目，发布说明称使用自反馈强化学习增强从零构建项目的能力，并缩短任务时长和输出。这里的“更省”是**单任务用量与运行时间的官方主张**，不是 token 单价下降；价格表显示 Flash 在北京时间高峰时段的每百万未命中输入/输出 tokens 为 **2/8 元**，空闲时段为 **1/4 元**。

**证据边界。** 这些成绩出自团队自测。Terminal-Bench 4.0 使用 Claude Code Harness，DeepSWE 使用 Mini-SWE-V2；团队还特别优化了 DeepSeek Harness、CodeBuddy 和 WorkBuddy。不能用单张表推出模型在 Codex、其他 Harness 或不同预算下同幅提升，也不能把演示项目视为可复现的长期工程能力。HLE 的带 † 数字仅针对纯文本子集；ZeroBench 为 Pass@5。此次为同家族版本更新，公开材料没有给出足以断言架构改动的细节。**投入建议：深入学习（半天）。** 先读模型卡的评测注释与 prompt 编码，再用固定 Harness、提示、时间预算和任务集重跑旧/新版本，记录成功率、墙钟时间、输出 tokens 与总费用；如果准备自部署，再核对权重格式及具体后端支持。

### DeepSeek Search/Fetch：Agent 可直接调用搜索和网页抓取

**质量：B｜重要性：中｜Personal Utility：中｜原始发布：2026-10-17，此前漏报。** [中文 API 指南](https://api-docs.deepseek.com/zh-cn/guides/search/)列出两个独立的 JSON 端点：`/v1/tools/search` 按 query 返回结构化结果，`/v1/tools/fetch` 抓取单页并返回 Markdown。Search 可限制站点、语言和日期，单次取 1～50 条；两个接口各有账号级 **5 QPS** 限制。成功且有结果的调用分别按 **5 元/千次**计费，失败或无结果不计。对使用 DeepSeek API 的 DeepSeek Harness、Claude Code、Codex 等服务端工具调用，[中文发布说明](https://api-docs.deepseek.com/zh-cn/news/news261017/)明确目前免费，**北京时间 2026-11-01 00:00** 起按次计费；这影响后续 Agent 任务成本估算。

独立调用接口、明确返回字段与计费规则有直接工程价值；但“千亿级索引”“过滤 SEO/GEO 垃圾”仍是官方描述，尚无可核验的检索质量、时效或故障率对照。Fetch 也受目标网站可用性与访问策略约束。**投入建议：了解即可（15 分钟）。** 若正在设计检索链路，可在一组固定中英文问题上对照现用搜索源的召回、来源可信度、抓取成功率及每任务调用次数，再决定是否接入。
