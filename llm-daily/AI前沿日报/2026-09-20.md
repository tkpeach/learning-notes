# 业界进展

### Anthropic 与 Accenture 试行嵌入式前沿模型评估

Anthropic 9 月 18 日宣布与 Accenture 的专业 AI 团队 Faculty 开展[嵌入式独立评估合作](https://www.anthropic.com/news/accenture-embedded-evaluation)：评估人员将获得接近内部员工的访问条件，跟踪训练中的模型、研发与部署决策，并进行红队、对齐与防护评估。双方预计未来五年至少各投入 10 亿美元建设相关能力，合作非独家，Anthropic 也在与 METR 等非营利机构讨论试点。这个模式比发布后外部测评更接近研发现场，但访问边界、报告标准、利益冲突与长期资金机制尚未确定，而且当前由被评估方直接出资。**重要性：高。建议投入：立即学习（1～3 小时），重点梳理评估独立性、可公开证据和事故报告权。**

### 智谱称 GLM Infra Agent 在两周内推进十万卡级推理栈投产

智谱 9 月 17 日的[工程复盘](https://z.ai/blog/glm-built-its-inference-infrastructure)称，GLM-5.3 驱动的 Infra Agent 参与了 GLM-5.3-Flash 在超过 10 万张国产 AI 加速器上的适配与优化：通过线性注意力和 LM Head 的节点内张量并行、ReplaySSM、W8A8、混合精度缓存量化、Layer Split 与 Encode-Prefill-Decode 解耦，将初始基线的端到端服务性能提高约 3 倍，并在不到两周内推进到生产。文章还称匿名上线后六天处理超过 62 万亿 token。它展示了 Coding Agent 从应用代码向 kernel、并行策略和部署反馈环扩展的方向；但硬件型号、工作负载、基线、尾延迟、质量回归和 Agent/人工贡献拆分均未充分公开，暂不能据此判断可迁移性。**重要性：高。建议投入：立即学习（1～3 小时），把公开的优化清单映射到自己的 serving 瓶颈；暂不把 3 倍结果当作独立基准。**

### Kimi Code 推出桌面端，把长期任务、浏览器与审批收进同一工作台

Kimi 9 月 17 日发布[Kimi Code Desktop](https://www.kimi.com/code/docs/en/kimi-code/whats-new.html)：将 CLI 的 Agent 核心带入 macOS 与 Windows 图形界面，提供可暂停、恢复和取消的 Goal 模式、先审计划再改文件的 Plan 模式、后台任务、内置浏览器、截图与元素标注，以及三档操作审批。同期 CLI v2.0 增加桌面端入口和终端 Mermaid 渲染。这是本地编码 Agent 产品形态的完整化，而非新的模型能力证明；目前缺少与 CLI、其他桌面 Agent 的受控效率和安全性比较。**重要性：中。建议投入：了解即可（5～20 分钟）。**

# 系统与编译器进展

### NVIDIA AIPerf 用多进程负载端重做生成式 AI 推理压测

NVIDIA 9 月 18 日将[AIPerf](https://developer.nvidia.com/blog/benchmarking-llm-inference-at-scale-with-aiperf/)定位为 GenAI-Perf 的后继者。它不再依赖原有 Perf Analyzer 路径，而用多个负载 worker、独立结果处理服务和 ZMQ 协调，降低 Python GIL 或单进程客户端先饱和而误判服务端上限的风险。工具支持 15 种以上端点、恒定/泊松/Gamma 到达模式、渐进加压、ShareGPT 与多种生产 trace 回放，并统一输出 TTFT、ITL、请求延迟、吞吐分位数以及 DCGM/pynvml 遥测。它解决的是“测量工具不能成为瓶颈”的基础问题；不过真实可信仍取决于 tokenizer、输出长度约束、warm-up、连接上限和服务端指标口径，官方示例不是跨引擎性能排名。**重要性：高。建议投入：深入学习（半天～2 天），先复现固定 ISL/OSL，再用真实 trace 和 SLA sweep 替换单一并发数字。**
