# 业界进展

### Qwen3.8-Omni-Flash 把音视频理解接入 Agent 工作流

Qwen 9 月 18 日发布[Qwen3.8-Omni-Flash](https://qwen.ai/blog?id=qwen3.8-omni-flash)：模型原生接收文本、图像、音频和视频，提供 1M 上下文、思考模式与函数调用，但当前只输出文本。它的主要增量是“主动感知”——面对长音视频先规划，再调用工具定位、核对证据，而不是一次性吞入全部媒体；官方还提供[Qwen-MM-Plugins](https://github.com/QwenLM/Qwen-MM-Plugins)，把转写、说话人分离、音视频定位与计数等能力暴露给 Agent。官方评测中，模型在 WildClawBench-MM 得分 71.0，高于其报告的 Gemini 3.8 Flash 58.9；但 AgenticVBench 为 36.8，低于 Gemini 的 45.0，说明优势并非全面。部分结果还使用 Qwen Code 等 harness，不能视为纯模型对比；目前主要是 API 能力，未见对应开放权重，基准也缺少独立复现。**重要性：高。建议投入：立即学习（1～3 小时），用一段带分散证据的长会议或视频验证“主动定位”是否同时降低 token、提高可追溯性。**

### Qwen3.8-LiveTranslate 强化实时说话人区分与上下文消歧

Qwen 同日发布[Qwen3.8-LiveTranslate](https://qwen.ai/blog?id=qwen3.8-livetranslate)，在 60 种语言实时同传基础上加入实时说话人分离、双语同步显示和长上下文消歧；官方称平均滞后从 2.8 秒降至 2.3 秒，并增强多人会议中的说话人归属与音色稳定性。它更接近实时会议基础能力升级，而不是通用 Agent 突破；目前缺少不同噪声、重叠语音、口音和领域术语条件下的独立对照。**重要性：中。建议投入：了解即可（5～20 分钟）；有跨语言会议需求时再用真实录音小规模验证。**

### ZCode 3.14.0 加入脚本化多子代理动态工作流

智谱旗下 ZCode 在 9 月 19 日发布的[官方更新日志](https://zcode.z.ai/cn/changelog)中加入动态工作流：用户可从输入框菜单或 `/workflow` 命令启动一段脚本，由多个子代理协作执行复杂任务。版本同时增加 Office/Coding 模式切换、独立使用 Start Plan、手机远控改进与自定义快捷键，并修复后台工作流会话从任务列表消失、取消或恢复被拒绝时缺少原因等问题。它的实质价值在于把任务分解与并行协作提升为产品级入口，而不是新增底层模型能力；官方尚未公开工作流 DSL、调度策略、失败恢复语义、成本控制和受控评测。更新还允许在审批弹窗直接授予完全访问权限，并提到修复“仓库百科异常上传”，企业使用前应核对权限、代码上传与审计边界，不应仅因操作更顺滑而放宽默认授权。**重要性：中。建议投入：了解即可（5～20 分钟）；有复杂仓库任务时先用低权限、小范围工作流验证恢复、成本和产物一致性。**

# 本期最值得关注

1. **Qwen3.8-Omni-Flash 的主动音视频理解。** 对长会议、课程和视频资料，最值得验证的是 Agent 能否先定位证据再精读，从而在准确率、token 成本和引用可追溯性上同时获益；建议投入 1～3 小时做一组静态整段输入与工具化主动定位的对照。
2. **ZCode 的动态工作流产品化。** 值得观察的不是“能调用多个子代理”本身，而是脚本化编排是否能稳定处理长任务中的权限、失败恢复、成本上限和结果验证；建议先用一个可重复、低风险的两阶段任务做小规模试验，再决定是否纳入日常开发流程。
